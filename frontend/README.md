# Frontend (staging)

This frontend folder contains the React app scaffold and production-ready copy in Bangla. The app is staged for your review — it is not yet publicly deployed until you approve the launch.

Key changes in this branch:
- Removed "demo" terminology and prepared production copy.
- Bangla-first copy added for Landing, Signup, Dashboard, Referral, and Bot microcopy.
- Placeholder logos/assets are in /branding/.

How to run locally:
1. cd frontend
2. npm install
3. npm start

When you are ready to go live, we will deploy to the domain you approve and connect the production token contract address.
